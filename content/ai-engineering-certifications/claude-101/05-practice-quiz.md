# 15-question practice quiz

Answer all 15 before opening the key; about 15 minutes is plenty. These are original practice questions written for this learning path from Anthropic's public help articles. They are **not** the Claude Academy quiz questions.

## Questions 1–10

**1.** Chats inside one project share what automatically?
A. The project's knowledge and its instructions
B. Every message from the other chats in the project
C. Nothing; each chat must be given the files again
D. Only the most recent chat's history and its files

**2.** You explain your bug-report format at the start of every chat, in and outside projects. Which feature removes that repetition everywhere?
A. A project with the format pasted into its knowledge
B. A custom skill that defines the bug-report format
C. A connector to your bug tracker's report template
D. Research, which looks the format up on the web each time

**3.** Which statement about connectors is true?
A. They give Claude admin rights in the connected app
B. They only read data and can never take any actions
C. Claude inherits your own permissions in the connected app
D. They work only in the desktop app and never on the web

**4.** You start Research from the mobile app with Slack connected. What does Claude search?
A. Slack first, then the web if Slack has nothing useful
B. Slack and the web together, just as on the desktop app
C. Only Slack, because connected tools take priority there
D. Only the web; Research on mobile skips your connectors

**5.** Which is the best example of an artifact?
A. A release-readiness dashboard you can edit and share
B. A one-line answer to a question about test coverage
C. A file uploaded to project knowledge for every chat
D. The instructions that set a project's tone and role

**6.** What does progressive disclosure mean for skills?
A. Users see more skills gradually as they move to bigger plans
B. Claude loads only relevant skills, and only what it needs
C. Each skill shows its instructions to you one step at a time
D. Claude loads every installed skill at the start of each chat

**7.** A teammate on your Team plan cannot add the Linear connector. What is the most likely reason?
A. The Linear connector needs a Max plan for every member
B. Connectors only work for the person who made the project
C. An Owner has not enabled that connector for the organization
D. The teammate must turn on Research before connecting apps

**8.** On a Free account you cannot create a sixth project. Why?
A. Projects beyond the first are part of a paid trial only
B. Each new project needs its own connector set up first
C. Free accounts must archive one project every week
D. Free accounts can create at most five projects

**9.** On a Pro plan, project knowledge is close to the context limit. What does Claude do?
A. Switches to retrieval (RAG) mode to expand the capacity
B. Deletes the oldest files so the project stays under it
C. Stops accepting new chats until you remove some files
D. Moves the extra files into a new, linked project

**10.** Which prompt follows the course's advice best?
A. "Write good test cases for our login page, please."
B. "Write 10 login test cases from the attached spec as a table."
C. "You are the best tester alive; test the whole login page."
D. "Login test cases. Be thorough, be creative and be quick."

## Questions 11–15

**11.** You need a comparison of three test-management tools, with sources you can check. Which feature fits?
A. A project with the three vendors' pricing pages
B. A skill that formats vendor comparisons as tables
C. Research, which searches in steps and cites sources
D. Enterprise search across your organization's tools

**12.** What has to be in place before you can use skills in Claude?
A. A Team or Enterprise plan for every member
B. At least one connector enabled for the account
C. A project that holds the skill as knowledge
D. Code execution turned on in your settings

**13.** Who can see an artifact you have just made?
A. Only you, until you share it
B. Everyone in your organization
C. Anyone with a link to the chat
D. Members of the current project

**14.** On a Team plan you want one cited answer to "What did we decide about flaky tests?" drawn from Slack, Gmail and Drive. Which feature is built for this?
A. A project with exported Slack threads as knowledge
B. Enterprise search across the connected tools
C. A custom skill that reads Slack, Gmail and Drive
D. Research started from the mobile app

**15.** What is the Claude 101 badge?
A. A proctored certification that is valid for 12 months
B. A paid credential issued after a Pearson-run exam
C. A completion badge for passing the course quizzes
D. A partner-only credential for Claude Partner Network staff

## Answer key with explanations

1. **A** — project knowledge and instructions apply to every chat in the project; chat histories stay separate.
2. **B** — a skill loads wherever the task matches it; a project only helps inside that project.
3. **C** — Claude sees and does only what your account in that service allows.
4. **D** — Research started on mobile searches only the web, with no warning that connectors were skipped.
5. **A** — artifacts are things you would put in front of someone: documents, dashboards, decks, tools.
6. **B** — Claude checks which skills fit the task and loads only what it needs, so the context stays small.
7. **C** — on Team and Enterprise plans an Owner or Primary Owner enables connectors first.
8. **D** — the Free plan allows at most five projects.
9. **A** — paid plans switch to retrieval mode, which expands project capacity up to ten times.
10. **B** — it states the task, the source, the scope and the output format; flattery and adjectives add nothing.
11. **C** — Research runs searches that build on each other and returns a report with citations.
12. **D** — skills need code execution turned on; they are available on every plan, Free included.
13. **A** — artifacts start private; nothing is shared until you share it.
14. **B** — enterprise search is a dedicated project that searches the organization's connected tools and cites sources.
15. **C** — Claude Academy badges mark course completion; proctored Claude certifications are separate exams.

## Score interpretation

This quiz uses one question = one mark. The real course quizzes only need passing, so use the score to decide what to reread:

- **14–15:** strong; take Claude 101 on Claude Academy now.
- **12–13:** close; reread the chapter behind each wrong answer.
- **11:** gaps remain; reread projects, skills and connectors, then retake.
- **Below 11:** read the three study chapters again before the course.
