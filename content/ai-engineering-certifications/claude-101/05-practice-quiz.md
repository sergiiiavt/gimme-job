# 15-question practice quiz

Answer all 15 before opening the key; about 15 minutes is plenty. These are original practice questions written for this learning path from Anthropic's public help articles. They are **not** the Claude Academy quiz questions.

## Questions 1–10

**1.** Which context is made available to chats within one project?
A. The project's knowledge and its instructions
B. Only the most recent chat's history and its files
C. Nothing; each chat must be given the files again
D. Every message from the other chats in the project

**2.** You repeatedly explain a bug-report procedure across supported tasks. Which feature packages it for reuse?
A. A connector to your bug tracker's report template
B. A custom skill that defines the bug-report format
C. Research, which looks the format up on the web each time
D. A project with the format pasted into its knowledge

**3.** Which statement about connectors is true?
A. Your service permissions still limit access
B. They give Claude admin rights in the connected app
C. They work only in the desktop app and never on the web
D. They only read data and can never take any actions

**4.** Research cites an old remote-work page and a current hybrid-work note. What should you do?
A. Prefer the public page regardless of date and role scope
B. Choose whichever label is repeated most often in the answer
C. Compare source dates/scope and retain unresolved conflict
D. Trust the model confidence instead of opening either source

**5.** Which is the best example of an artifact?
A. An editable readiness dashboard
B. A one-line answer to a question about test coverage
C. The instructions that set a project's tone and role
D. A file uploaded to project knowledge for every chat

**6.** What does progressive disclosure mean for skills?
A. Users see more skills gradually as they move to bigger plans
B. Claude loads every installed skill at the start of each chat
C. Claude loads only relevant skills, and only what it needs
D. Each skill shows its instructions to you one step at a time

**7.** A Team teammate cannot add a connector. Which prerequisite should you check first?
A. The Linear connector needs a Max plan for every member
B. Connectors only work for the person who made the project
C. An Owner has not enabled that connector for the organization
D. The teammate must turn on Research before connecting apps

**8.** Before sharing an artifact created during project work, what must you check?
A. Assume every project member sees every related artifact
B. Treat a connector installation as public-sharing permission
C. Assume chat links and artifact links grant the same access
D. The artifact’s actual audience and access settings

**9.** On a Pro plan, project knowledge is close to the context limit. What does Claude do?
A. Moves the extra files into a new, linked project
B. Switches to retrieval (RAG) mode to expand the capacity
C. Deletes the oldest files so the project stays under it
D. Stops accepting new chats until you remove some files

**10.** Which prompt follows the course's advice best?
A. "Login test cases. Be thorough, be creative and be quick."
B. "Write 10 login test cases from the attached spec as a table."
C. "Write good test cases for our login page, please."
D. "You are the best tester alive; test the whole login page."

## Questions 11–15

**11.** You need a comparison of three test-management tools, with sources you can check. Which feature fits?
A. A project with the three vendors' pricing pages
B. Enterprise search across your organization's tools
C. Research, which searches in steps and cites sources
D. A skill that formats vendor comparisons as tables

**12.** What does a report-formatting skill NOT provide by itself?
A. External permissions or credentials not otherwise granted
B. Reusable procedure instructions for writing the report
C. Context that explains how the procedure should be followed
D. Guidance about the expected structure of the report

**13.** Who can see an artifact you have just made?
A. Anyone with a link to the chat
B. Everyone in your organization
C. Members of the current project
D. Only you, until you share it

**14.** On a Team plan you want one cited answer to "What did we decide about flaky tests?" drawn from Slack, Gmail and Drive. Which feature is built for this?
A. A project with exported Slack threads as knowledge
B. Enterprise search across the connected tools
C. A custom skill that reads Slack, Gmail and Drive
D. Research started from the mobile app

**15.** What is the Claude 101 badge?
A. A partner-only credential for Claude Partner Network staff
B. A paid credential issued after a Pearson-run exam
C. A proctored certification that is valid for 12 months
D. A completion badge for passing the course quizzes

## Answer key with explanations

1. **A** — Project knowledge and instructions are available; retrieval does not promise that every file is copied verbatim into every turn.
2. **B** — A skill packages the repeatable procedure; it does not create external access or guarantee support in every product surface.
3. **A** — Effective access also depends on granted connector scopes and organization policy; a model cannot create admin rights by requesting them.
4. **C** — A citation is not proof of freshness or support; source conflict needs investigation, not majority vote among copied claims.
5. **A** — Artifacts are separate work products such as documents or dashboards; project instructions and knowledge are context.
6. **C** — Claude checks which skills fit the task and loads only what it needs, so the context stays small.
7. **C** — on Team and Enterprise plans an Owner or Primary Owner enables connectors first.
8. **D** — Check the actual object and audience; project, chat and artifact access are not automatically interchangeable.
9. **B** — paid plans switch to retrieval mode, which expands project capacity up to ten times.
10. **B** — it states the task, the source, the scope and the output format; flattery and adjectives add nothing.
11. **C** — Research runs searches that build on each other and returns a report with citations.
12. **A** — Procedural guidance does not authorize access to a tracker; the connected service still controls credentials and permissions.
13. **D** — artifacts start private; nothing is shared until you share it.
14. **B** — enterprise search is a dedicated project that searches the organization's connected tools and cites sources.
15. **D** — Claude Academy badges mark course completion; proctored Claude certifications are separate exams.

## Score interpretation

This quiz uses one question = one mark. The real course quizzes only need passing, so use the score to decide what to reread:

- **14–15:** strong; take Claude 101 on Claude Academy now.
- **12–13:** close; reread the chapter behind each wrong answer.
- **11:** gaps remain; reread projects, skills and connectors, then retake.
- **Below 11:** read the three study chapters again before the course.
