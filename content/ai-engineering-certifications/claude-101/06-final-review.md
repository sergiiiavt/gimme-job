# Final review

Examples of Claude features across everyday work and available interfaces.

## Use cases by role

| Role | A good first use |
| --- | --- |
| QA engineer or QA lead | Test cases from a spec, bug-report drafts from logs, a release-readiness summary from test results |
| Developer | Explaining unfamiliar code, drafting tests, reviewing a diff; move to Claude Code for work inside a repository |
| Product or project manager | Turning meeting notes into decisions and actions, drafting specs, comparing options with Research |
| Analyst | Cleaning a spreadsheet, building a chart or a dashboard artifact from an export |

## Other ways to work with Claude

- **Mobile apps** for quick questions and voice on the go.
- **Office add-ins** for Excel, PowerPoint, Word and Outlook, which also use the skills you have enabled.
- **Claude in Chrome**, a browser extension that works on web pages for you.
- **Claude Code** for software work in a repository; see the Claude Code 101 tile.
- **The Claude API** for building Claude into your own product; see the Claude Platform 101 tile.
