# Claude Platform 101: course map & badge

Claude Platform 101 is Anthropic's free developer course on **Claude Academy** (academy.claude.com). It teaches building on the Claude Platform from the ground up, whether you have made a few API calls or have only used Claude in a chat window. Every lesson ends with a runnable demo. Passing the course quiz earns a completion badge. It is a course badge, not a proctored certification.

## Course facts

- **Cost:** the course is free. Running the demos uses your own API key from the Claude Console and spends API credit.
- **You need:** basic programming. No prior experience with agents is required, because each lesson builds on the one before.
- **Assessment:** the Claude Platform 101 quiz at the end. Passing earns the badge, and retakes are unlimited.
- **Badge:** comes with a PDF, a LinkedIn share button and a public verification link, and it does not expire.

## What the course covers

| Course section | Lessons | Chapter in this track |
| --- | --- | --- |
| What is the Claude Platform? | The platform, your first API call, choosing the right model | First request & model choice |
| Teaching your agent | The agent loop explained, tool use, thinking | Agent loop & tools |
| Extending your agent | Built-in tools, skills, MCP, context management | Extending your agent |
| Managed agents | What managed agents are, building your first one | Extending your agent |
| Building with Claude Code | Using Claude Code to build against the API | Hands-on lab |
| Quiz | Claude Platform 101 quiz | Practice quiz |

## Study plan

1. Read the three study chapters in this track; together they take about an hour.
2. Do the hands-on lab; it takes about 90 minutes with an API key.
3. Take the 15-question practice quiz and aim for 13 or more.
4. Take Claude Platform 101 on Claude Academy and pass its quiz.
5. List the badge under Training on your CV, and keep the lab's agent in a public repository to show in interviews.

This course is also the best free preparation for the API-heavy parts of the proctored Claude CCDV-F and CCAR-F exams.
