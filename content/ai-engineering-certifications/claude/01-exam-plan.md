# Exam map & study plan

This track prepares you for **Claude Certified Architect – Foundations (CCAR-F)** and adds the API depth for **Claude Certified Developer – Foundations (CCDV-F)**. Both are proctored Anthropic exams. Study the material even if you cannot sit them yet: it is exactly what senior AI-agent interviews probe.

## Who can sit the exams

Only employees of companies in the **Claude Partner Network** can certify, and registration needs a partner email on a recognised company domain. Customers and non-partners are not eligible yet. Partner Network membership is free for organizations, so the first question to ask is whether your employer is already a partner.

If you are not eligible, the free **Anthropic Academy** courses issue completion certificates that anyone can earn: Claude Code in Action, Building with the Claude API, Introduction to Model Context Protocol, MCP Advanced Topics, and Introduction to Agent Skills.

## Exam facts to memorise

- **Time:** 120 minutes of testing; plan for about 135 minutes in the seat.
- **Format:** multiple choice and scenario-based multiple response, closed book, English only.
- **Delivery:** Pearson OnVUE online proctoring or a Pearson test center.
- **Score:** scaled from 100 to 1,000; **720 passes** every Claude exam.
- **Retakes:** wait 14 days, then 30, then 90; at most 4 attempts per exam in a rolling 12 months, full fee each time.
- **Validity:** 12 months. On-time renewal is a free, unproctored assessment; a lapse means retaking the full exam.
- **Readiness:** Anthropic recommends a practice-exam score of 900 or more before booking CCAR-F.

## CCAR-F domains and the six scenarios

| Domain | Weight |
| --- | --- |
| Agentic architecture and orchestration | 27% |
| Claude Code configuration and workflows | 20% |
| Prompt engineering and structured output | 20% |
| Tool design and MCP integration | 18% |
| Context management and reliability | 15% |

Each sitting draws **4 of 6** published production scenarios, with roughly 15 questions each: customer support resolution agent, code generation with Claude Code, multi-agent research system, developer productivity with Claude, Claude Code for CI/CD, and structured data extraction. Study all six; they overlap heavily in the skills they test.

## CCDV-F domains

CCDV-F is an API exam. Its weights, as reported from the July 2026 candidate guide, are: applications and integration 33.1%, model selection and optimisation 16.8%, agents and workflows 14.7%, prompt and context engineering 11.0%, tools and MCPs 10.6%, security and safety 8.1%, Claude Code 3.1%, and evaluation, testing and debugging 2.6%. Pearson announced updated content from **7 December 2026**, so recheck the guide before booking.

## How to use this track

1. Read the five domain chapters in order, then the developer API chapter.
2. Do at least three of the hands-on labs; hands-on time is what separates a pass from a near miss.
3. Take the 40-question mock exam under an 80-minute timer.
4. Use the final review's distractor patterns to explain every wrong answer.

A realistic pace is four weeks for CCAR-F at about an hour a day, plus two weeks for the CCDV-F delta.
