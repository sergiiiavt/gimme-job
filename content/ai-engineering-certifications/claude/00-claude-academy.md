# Claude Academy: the free 101 courses

Start here. Claude Academy is Anthropic's free course site at **academy.claude.com**. It was called Anthropic Academy and ran on Skilljar until 20 August 2026. Each 101 course takes an hour or two, and passing its quizzes earns a completion badge you can add to LinkedIn the same day. It is the quickest proof on a CV that you have actually used Claude, and it covers the basics the proctored exams assume.

## The three 101 courses

| Course | Take it if | What it covers | You need |
| --- | --- | --- | --- |
| Claude 101 | You use Claude at work | Better prompts, projects, artifacts, skills, connectors, Research and the desktop app | Any Claude account, including Free |
| Claude Code 101 | You write or test code | Installing Claude Code, permission modes and Plan Mode, explore → plan → code → commit, context commands, CLAUDE.md, subagents, skills, MCP and hooks | Claude Pro, Max or Enterprise, or an API key |
| Claude Platform 101 | You build on the API | First API call, choosing a model, the agent loop, tool use, extended thinking, built-in tools, skills, MCP, context management and managed agents | Basic coding and an API key for the demos |

For a QA engineer the order is Claude 101, then Claude Code 101, then Claude Platform 101. If you already use Claude every day, skim Claude 101 and spend the saved time on the other two.

## Earning the badge

- Sign in at academy.claude.com with any Claude account, including Free. You can browse without signing in, but only signed-in progress counts.
- Pass all of the course's quizzes. Retakes are unlimited.
- The badge comes with a PDF, a LinkedIn share button and a public verification link, and it does not expire.
- Started a course on Skilljar before the move? Your progress imports when your Skilljar email matches your Claude account.
- Claude Code is not part of the Free plan, so the hands-on parts of Claude Code 101 need a paid plan or an API key.

## Badges are not certifications

A completion badge shows you finished a course. It is not a proctored exam, so list it honestly:

- **LinkedIn:** add it under Licenses & certifications with the course name, Anthropic as the issuing organization, and the verification link as the credential URL.
- **CV:** put badges under Training or Courses. Keep Certifications for proctored exams such as CTFL or CCAR-F. Interviewers who check notice the difference, and the honest label reads better.
- **Interview:** be ready to show something you built after the course, such as a CLAUDE.md with team rules, a hook that blocks a risky command, or a subagent that reviews tests. Labs 2 and 5 in this track build all three.

## After the 101s

For CCAR-F, Anthropic recommends Claude 101, Building with the Claude API, Introduction to Model Context Protocol and Claude Code in Action, plus hands-on building with its developer tools. Add Introduction to Agent Skills if you use Claude Code daily. All of them are free on Claude Academy and earn the same kind of badge.

If your employer is in the Claude Partner Network, the partner academy also has a ten-course Claude Architect learning path that leads into the exam. The next chapter explains who can sit the exams.
