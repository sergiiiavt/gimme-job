# Exam map

This track prepares you for **GH-300: GitHub Copilot**, the Microsoft-administered GitHub certification for developers who use Copilot to improve productivity, quality and security. Unlike the Claude exams, anyone can book it.

## Exam facts

- **Time:** about 100 minutes, proctored online or at a test center through Pearson VUE.
- **Questions:** multiple choice and multiple response.
- **Score:** 700 of 1,000 passes.
- **Price:** about $99 in the United States; the price depends on the country where you sit it.
- **Outline:** skills measured as of 7 August 2026, which added Copilot CLI, agent sessions, sub-agents, Spaces and Spark.
- **Language allowance:** if the exam is not offered in your preferred language, you can request 30 extra minutes.
- **Practice:** Microsoft Learn offers a free practice assessment and an exam sandbox that shows the question types.

## Domains

| Domain | Weight |
| --- | --- |
| Use GitHub Copilot features (IDE, CLI, agents, org policies) | 25–30% |
| Use GitHub Copilot responsibly | 15–20% |
| Understand Copilot data and architecture | 10–15% |
| Apply prompt engineering and context crafting | 10–15% |
| Improve developer productivity, including tests and security | 10–15% |
| Configure privacy, content exclusions and safeguards | 10–15% |

The official page also lists a second "GitHub Copilot features" domain at 25–30% with no sub-skills; treat it as part of the first.
