# Карта іспиту GitHub Copilot GH-300

Підготовка спирається на актуальний Microsoft Learn study-guide. Власні запитання не є офіційними екзаменаційними матеріалами.

## Факти про іспит

GH-300 має scaled passing-score700/1000 і приблизно 100 хвилин assessment-time за certification-page. Поточні мови, booking, регіональну ціну й правила renewal перевіряйте в Microsoft Learn; GitHub credentials не слід автоматично підпорядковувати правилам інших Microsoft-certifications.

## Домени

Responsible AI, features, data/architecture, prompting/productivity та privacy/safeguards. Офіційний guide задає scope й може змінювати ваги/перелік задач. Дублювання bullet у guide не є новим окремим механізмом продукту.

## Типові труднощі

Плутанина instruction-guidance з enforcement; exclusion із sandbox; accepted-code з verified-code; capability одного client із підтримкою всюди. Відповідь має враховувати plan, surface, policy та реальний oracle.

## Як навчатися

Пройдіть тематичні lessons, виконайте scratch-lab і поясніть помилки original mock. Перевіряйте актуальні docs для свого client/version. Навчальний percentage не перераховується в 700 scaled-score.

## Від guide до evidence

Responsible-use→source checks; features→підтримуваний client; data→account-policy; prompting→точний базис; privacy→перевірка exclusion на synthetic-data. Збережіть applied evidence, а не лише число правильних відповідей.
