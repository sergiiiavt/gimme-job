# Claude Code 101: course map & badge

Claude Code 101 is Anthropic's free course on **Claude Academy** (academy.claude.com) for developers who are new to Claude Code or to AI coding agents. It runs from installation to customization. Passing the course quiz earns a completion badge. It is a course badge, not a proctored certification.

## Course facts

- **Cost:** free.
- **You need:** basic familiarity with a code editor and the command line, and either a Claude Pro, Max or Enterprise account or an API key. Claude Code is not part of the Free plan.
- **Time:** about two hours, self-paced.
- **Offline examples:** Python and Git; live Claude Code examples also require a supported account/API setup.
- **Assessment:** the course quiz. Passing earns the badge, and check current assessment/retake rules in the course.
- **Badge:** is evidence of course completion; check the issued credential for its verification, sharing and validity details.

## Learning objectives

- Explain how an AI coding agent differs from a chat assistant, and how the agent loop, the context window, tools and permissions fit together.
- Install Claude Code and use it in the terminal, an IDE, the desktop app or the web.
- Work in the right permission mode: asking first, auto-accepting edits, or Plan Mode.
- Explore, plan, edit and review a repository change.
- Manage the context window with /context, /compact and /clear.
- Keep project memory in CLAUDE.md, delegate to subagents, connect MCP servers and add hooks.
