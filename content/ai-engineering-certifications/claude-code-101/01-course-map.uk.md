# Claude Code 101: карта курсу

Курс про роботу з coding-agent у реальному репозиторії. Починайте з безпечної копії та перевірного локального завдання.

## Факти про курс

Актуальні умови completion-badge перевіряйте в Claude Academy. Optional live-practice потребує підтримуваного account/API setup та usage-budget. Offline-вправи потребують Python/Git, без платних calls; жоден конкретний перелік subscriptions не є вічним.

## Зміст

Agent-loop, контекст і permissions; Explore/Plan/Code; project-memory, subagents, skills, MCP і hooks. Guidance, execution і backend-authorization виконують різні ролі.

## Очікувані вміння

Дослідити codebase, відтворити bug, зробити мінімальний fix, запустити meaningful tests і пояснити diff. Показати hook-block та його межі. Не стверджувати, що перевірка виконана, без результату запуску.

## План

Прочитайте теми, виконайте lab, проаналізуйте error-case й original quiz. Перед live-agent перевірте commands і permissions. Для нечіткої великої зміни план потрібен; для малих fixes масштабуйте процес.

## Передумови та evidence

Додайте незалежний failing-test для member/100, виправте > на >= і збережіть diff/commands/results. Використовуйте scratch-copy, а не production-config. Зелений fixture-run покриває перелічені cases, не всю систему.
