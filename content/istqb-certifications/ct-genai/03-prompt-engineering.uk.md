# Промптинг для ефективного тестування

П’ять прикладних цілей цього розділу потребують перевірних задач. Ризик-ідентифікація GenAI-3.1.2 також належить до K3.

## Шість компонентів

Роль; контекст; інструкція; вхідні дані; обмеження; формат виходу. Приклад: роль test analyst, checkout як контекст, вивести умови з R1, без вигаданих правил, таблицею ID/умова/очікування. Роль не створює реальних повноважень.

## Основні техніки

Chaining ділить роботу з перевіркою між кроками. Zero/one/few-shot означає нуль/одну/кілька демонстрацій. Meta prompting створює чи вдосконалює промпт. Їх можна поєднувати, але приклади форми не гарантують правильних очікувань.

## System і user prompt

System задає поведінку від застосунку, user передає задачу та дані. Застосунок може змінювати system між запитами; сталий текст сесії не є універсальною гарантією. Позначення даних тегами не замінює захист від prompt injection.

## Застосування до тестових задач

Аналіз: неоднозначність, умови й покриття. Дизайн/реалізація: кейси, дані, скрипти. Регресія: impact analysis, reports і кластеризація. Monitoring/control: метрики, тренди та пропозиції пріоритетів. Джерело й перевірка потрібні в кожній задачі.

## Оцінювання результатів

Precision=TP/(TP+FP), recall=TP/(TP+FN). Якість змісту, релевантність, різноманіття та виконуваність вимірюють різні властивості. Порівнюйте унікальні ID та явно обробляйте порожній знаменник. Один успішний запуск не доводить правильність assertions.

## Удосконалення промптів

Порівнюйте версії на тих самих задачах, аналізуйте типи помилок і слабкі сегменти, збирайте людський feedback. Фіксуйте версію промпту, моделі та базису; випадковий вдалий приклад не є доказом поліпшення.

## П’ять прикладних задач

R1 задає знижки 0/5/10/20% за membership і subtotal>=100. Побудуйте промпт із шести компонентів; виведіть усі 4 правила; створіть 99/100 для обох ролей і звірте з незалежною таблицею; проаналізуйте зміну >= на >; сформуйте звіт із 200 planned,160 passed,24 failed,16 blocked.

Очікування:184 executed,92% completion,87.0% passed/executed. Для істинних D1,D2,D3 і передбачених D1,D2,D4,D4:TP2,FP1,FN1, precision=recall=2/3. Дублікат не збільшує true positives. Рішення про реліз потребує уповноваженого власника.
