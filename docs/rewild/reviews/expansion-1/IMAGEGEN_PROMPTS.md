# Expansion Pack 1 image-generation prompts

Both sheets were generated with the built-in image-generation workflow. The approved vertical-slice target and existing object assets were supplied as style, scale, palette, and perspective references. Flat magenta source sheets were converted locally to alpha PNG masters, then reduced to 50% with nearest-neighbor sampling.

## Tree response states

Use case: stylized-concept. Asset type: production modular sprite sheet for a 2D pixel-art tower-defense game. Image 1 is the authoritative world direction; Image 2 is the existing healthy deciduous tree; Image 3 is the existing healthy pine. Create exactly ten separate freestanding tree sprites in a strict 5-column by 2-row layout. Top row: the same deciduous tree in healthy, stressed, corrupted, dead, and recovering states. Bottom row: the same pine in those five states. Preserve trunk shape and family silhouette so each row reads as one object changing over time. Make every change physical: foliage thins, needles brown, branches break, bark sickens, residue accumulates, and fresh shoots return. Do not tint a healthy sprite. Match the approved handcrafted crisp pixel art, three-quarter camera, gameplay density, upper-left light, and earthy palette. Each object needs a clean, consistent ground pivot and empty space around it. Use a perfectly flat `#ff00ff` chroma background. No baked meadow, generic ground patch, broad shadow, text, labels, grid, hex outline, UI, or watermark.

## Pond response states

Use case: stylized-concept. Asset type: production modular sprite sheet for a 2D pixel-art tower-defense game. Image 1 is the authoritative world direction and Images 2–3 are the existing pond references. Create exactly eight separate pond sprites in a strict 4-column by 2-row layout. Preserve one wide irregular footprint in the top row and one compact irregular footprint in the bottom row. Each row shows clean, source-contaminated, severely polluted, and recovering states. Make the transition physical: water color and clarity change, reeds wilt or return, shoreline mud and residue accumulate, debris appears, then clean inflow and new growth restore the edge. Do not tint a clean pond. Match the approved handcrafted crisp pixel art, three-quarter camera, gameplay density, upper-left light, and earthy palette. Keep the same ground pivot and silhouette family within each row, with empty space around every object. Use a perfectly flat `#ff00ff` chroma background. No meadow rectangle, generic ground patch, broad shadow, text, labels, grid, hex outline, units, UI, or watermark.
