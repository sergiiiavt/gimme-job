# Compact quick-reference prototype

This iteration intentionally tests the dense reference treatment on the Programming / Python path before authoring the other supported references.

## Navigation contract

- Quick Reference is exposed only for the four original document-style learning paths: QA Fundamentals, Programming, Test Automation, and Cloud & DevOps.
- Opening Quick Reference does not replace the second-level learning navigation.
- The second panel keeps the same topic list and track switcher as the learning page.
- Selecting a topic or track exits Quick Reference and opens the corresponding learning view.

## Density contract

- No page hero, page title, descriptive intro, prototype badge, or result counter.
- The only page-level controls are scope tags and search, kept on one compact line when space permits.
- Cards use smaller type, tighter padding, lighter borders, and an auto-fitting dense grid.
- Python is the populated prototype; other supported references remain placeholders until the layout is approved.
